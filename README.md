## Hi, I'm David

I like building tools for things I actually use. Most of my projects start as a fix for something that bugs me, and I try to take them all the way to something deployed that other people can use.

### Projects

[Lorekeeper](https://github.com/David-Olah/Lorekeeper-showcase) is a campaign wiki for D&D groups that publishes notes straight from an Obsidian vault. The DM's private notes stay private, players get their own notes on every page, and shared group notes update live for everyone. It's built with React, Node.js, Express, PostgreSQL and WebSockets, plus an Obsidian plugin written in TypeScript. You can [try the live demo](https://lorekeeper-my6h.onrender.com/c/the-ashen-vale-demo).
